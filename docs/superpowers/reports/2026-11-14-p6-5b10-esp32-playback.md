# P6.5b10 ESP32 播放验收

生产 Tivoo Satellite 使用 `preferred_format=mp3`。NAS 上的 HA 2026.11.0 使用生产 Sherpa Matcha TTS 引擎和同一格式选项，TTS Proxy 返回 HTTP 200、`audio/mpeg` 和 47,331 字节。ffprobe 确认为 22,050 Hz 单声道 MP3，时长 4.60 秒。同一 HA 容器的转码入口也通过分段输入验证，WAV data 长度字段为 0 时，原始 PCM 可转成有效 MP3。

ESP32 按 1 KiB HTTP 读块增量解码。已锁定的 esp_audio_codec 2.6.2 解析 MP3，esp_audio_effects 1.4.5 按实际解码采样率有状态重采样。立体声先混为单声道，输出为 32 kHz Philips I²S，两个 32-bit slot 使用相同样本。PCM5102 DIN 接 GPIO27，共用 GPIO26 BCLK 和 GPIO25 WS。RX 使用 GPIO34。I²S 中断驻留 IRAM。播放 worker 固定在 core 0，AFE 继续在 core 1。

PCM 软件环容量 2,560 样本。DMA 确认最后一块 PCM 加一个 FIFO 保护块后，才发送 `completed`。STOP 清空软件环并在 TX EOF 上静音待发描述符，保留共享时钟和已进入 FIFO 的尾部。HTTP worker 独占客户端，STOP 对已建立的 socket 执行 shutdown 以唤醒读操作。连接建立阶段采用 1.5 秒传输超时，HTTP body 读等待为 8 秒。活动请求、一个待接替请求和最近 16 个播放/STOP ID 各有界，输出按 generation 隔离。

AEC R 取最终双槽 PCM，按 DMA 位置生成 16 kHz mono 参考。参考环保留 32 个 5 ms 块，补偿量默认 80 样本（5 ms）。该数值是可配置初值。需要接好 AUX 并做声学测量才能标定实际延迟。RX 丢描述符时跳过对应的参考时间并记录错位。TX 记录欠载、错过 EOF、软件环高水位以及实际交给 AFE 的参考峰值。

## 复测

在 NAS 释放 7778 和 7777 的 HA 连接后运行下列命令。使用至少 3 秒的真实 MP3。SPP 已配对连接时，脚本在播放期间发状态查询并验证回包。

```sh
python3 -u p65b10_device_acceptance.py <ESP32_IP> <fixture.mp3> \
  --http-host <NAS_LAN_IP> --require-spp
```

脚本覆盖 chunked 完整播放、重复播放 ID、过期 STOP、进行中的 HTTP/PCM 停止、新播放接替、无效 MP3、HTTP 截断、503、MIME 不匹配和 WAV 格式拒绝。记录的 STOP 延迟从发送 TVIO 指令到收到 `stopped`，测量位置在 NAS。原始镜像与测试日志保存在 NAS `/volume1/docker/tivoo-esptool/artifacts/p65b10/`。

## 验收状态

| 项目 | 结果 |
|---|---|
| ESP-IDF 构建、上板 | PASS。使用 NAS `tivoo-esptool` 只刷写应用分区 `0x10000` 并校验哈希，保留分区表、NVS 和已配对的 SPP bond。 |
| 主机回归 | PASS。ESP32 55 项、HA 351 项。HA 与 ESP32 测试分别运行，HA 测试插件的 socket 限制仅用于 HA 测试。 |
| 模拟输出、电气与声学对齐 | GAP。PCM5102 DIN 已连接 GPIO27。Tivoo AUX 未连接，设备在远程，无法测量模拟输出电平、DAC 停音、试听或标定实际 AEC 延迟。 |
| 真人语音和持续 MIC 上传 | GAP。实测 AFE 在播放和 STOP 前后持续运行。当前麦克风仍有 b8 报告中记录的持续 speech 状态，未形成新的 MIC 会话来验证上传同时进行。 |
| 生产格式数字链路与 SPP 并发 | PASS。22.05 kHz 单声道生产 MP3 完成两轮，播放期间通过 7777 收到真实 Tivoo SPP 状态回包。匹配 STOP 到 TVIO `stopped` 为 75.9 ms。最终 TX 参考峰值 17,098，AFE 无 feed/fetch 错误、RX overrun 或参考错位。两轮正常播放分别记录 9 和 0 个 TX 欠载块，TX 缺失 EOF 累计 25 次且在这几轮期间未增加。 |
| 44.1 kHz 立体声压力对照 | GAP。完成解码/SRC、SPP 并发和终态检查，STOP 到 `stopped` 为 58.7 ms。两轮正常播放记录 228 和 277 个 TX 欠载块。整个立体声用例后累计 64 次 RX overrun、51 次 AFE feed 错误和 68 次参考错位。当前板卡未达到这个格式的连续播放和采集指标。 |

本次最终应用镜像大小 1,721,264 字节，SHA-256 为 `a1c05bef18c9c0c100864ae08a6cbefe9c760e48c1351de16558eb33b0de926b`。设备测试短暂停止 HA 以释放每端口唯一 TCP 客户端，结束后恢复 HA。
